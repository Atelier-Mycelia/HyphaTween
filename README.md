# HyphaTween
A simple tweening system

# 📦 Installation

## Git URL
Add this package with Package Manager, going with Add Package From Git Url instead of Add Package From Disk:
1. https://github.com/Atelier-Mycelia/CommonLib.git?path=Assets/AtMyceliaCommonLib

## UPM from Disk
If the Git URL method didn't work, try this:
1. Download a release from [CommonLib's Releases page](https://github.com/Atelier-Mycelia/CommonLib/releases/tag/1.3.1)
2. Download a release from the this repo's Releases page
3. Extract both into a folder you use for on‑disk UPM packages
4. Open your Unity project
5. Go to Package Manager
6. Click + → Add package from disk
7. Select the package.json inside Assets/AtMyceliaCommonLib, and when that's done installing...
8. Select the package.json inside Assets/HyphaTween
